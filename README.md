# NOVA — Deep Space

NOVA — космическая исследовательская игра. Основная версия приложения находится в каталоге [`nova-world`](./nova-world/).

## Запуск

- [Открыть игру на GitHub Pages](https://a34147488-max.github.io/Bot/)
- Главная страница перенаправляет в `nova-world/`.

## Возможности

- Исследование космических секторов и карта звёздной системы.
- Корабль, ангар и улучшения модулей.
- Сканирование аномалий, лаборатория и технологии.
- Контракты, ресурсы, пассивная добыча и архив достижений.

Игра размещается как статический сайт; отдельный Node.js Telegram-бот для поиска по номеру телефона или генерации видео не используется.
