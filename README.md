# Анонимные сообщения — Telegram Mini App

Приложение открывается внутри Telegram и через Railway. Люди получают личную ссылку, переходят по ней в @generateii_bot и отправляют сообщение боту; сообщение появляется во входящих получателя в приложении. Отправитель не показывается получателю.

## Запуск на Railway

1. Подключите репозиторий `a34147488-max/Bot` к Railway как Node.js сервис.
2. Добавьте PostgreSQL в этот же Railway project. В сервисе приложения подключите переменную `DATABASE_URL` от PostgreSQL.
3. В Variables сервиса приложения задайте:
   - `BOT_TOKEN` — токен @generateii_bot из BotFather (держите секретным).
   - `BOT_USERNAME` — `generateii_bot` (по умолчанию уже задан).
   - `WEBHOOK_SECRET` — случайная секретная строка из букв, цифр, дефисов и подчёркиваний.
   - `APP_URL` — публичный HTTPS URL Railway-сервиса, например `https://ваш-домен.up.railway.app/`.
4. В Settings сервиса создайте публичный домен (Generate Domain). После этого Railway задаст `RAILWAY_PUBLIC_DOMAIN`; сервер автоматически зарегистрирует Telegram webhook при старте.
5. Откройте `https://ваш-домен.up.railway.app/health`: должно вернуться `{"ok":true}`.
6. Напишите боту `/start), нажмите «Открыть приложение», получите ссылку и проверьте отправку сообщения с другого Telegram-аккаунта.

Сервис автоматически создаёт таблицы `anon_messages` и `anon_sessions`. Команда запуска: `npm start`.

## GitHub Pages

GitHub Pages остаётся только статической копией интерфейса и не имеет доступа к базе данных. Для полноценной работы открывайте приложение через кнопку бота на Railway-домене.

## Безопасность

- Никогда не добавляйте `BOT_TOKEN` в код, HTML или GitHub.
- Не публикуйте значения секретных переменных в чатах и скриншотах.
- В приложении доступны только сообщения пользователя, подтверждённого через подписанные Telegram Mini App `initData`.
