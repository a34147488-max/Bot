# NOVA — космическая экспедиция

Самостоятельная мини-игра для браузера: исследуй сектора, выполняй миссии, открывай новые миры и прокачивай уровень экспедиции.

## Запуск
Открой `index.html` в браузере. Никакой сборки, сервера, токена бота, базы данных или платных API не требуется. Прогресс сохраняется локально в браузере через `localStorage`.

## Публикация
Папку `nova-world` можно опубликовать как статический сайт на любом хостинге, который раздаёт HTML/CSS/JS. Внешний шрифт загружается с Google Fonts; если он недоступен, используются системные шрифты.

## Файлы
- `index.html` — структура интерфейса
- `style.css` — адаптивный космический дизайн
- `app.js` — миссии, энергия, открытия и локальное сохранение

Это отдельный проект в подпапке и он не заменяет существующие файлы бота в корне репозитория.
